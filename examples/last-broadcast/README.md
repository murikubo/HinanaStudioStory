# 마지막 방송이 끝나기 전에

Hinana Studio Story 0.4.0으로 편집·재생할 수 있는 약 5분 분량의 한국어 단편 비주얼 노벨입니다.
폐교를 앞둔 학교 방송실에서, 성인이 된 두 옛 방송부원이 마지막 인사를 녹음합니다.

## 열기

제작기의 **열기**에서 `마지막 방송이 끝나기 전에.hinanastory`를 선택합니다.
처음 장면은 **01 · 먼지가 기억하는 목소리**입니다. 이 장면에서 **플레이 테스트**를 누르면 처음부터 재생합니다.
**연결** 탭에서 모든 분기와 합류·엔딩을 확인할 수 있습니다.
프로젝트 파일 하나에 배경·캐릭터·오디오가 포함되어 있어 다른 PC로 복사해도 열 수 있습니다.
파일은 약 16MB이며, 브라우저 로컬 자동 복구의 저장 한도를 넘을 수 있으므로 프로젝트 파일을 보관해 주세요.

개발 서버가 실행 중이면 `node examples/last-broadcast/open-in-studio.mjs`로 별도 개발 창에 샘플을 열 수 있습니다.
이 창은 `.preview-profile/`을 사용하여 기존 제작기의 복구 데이터와 분리됩니다.

## 구성

- 전체 9개 장면, 88개 블록
- 한 경로 65개 블록, 대사·서술 약 4,000자
- 선택 구간 3개 (초반 선택 2회와 마지막 선택 1회)
- 선택 변수 **함께 낸 용기**와 조건부 마지막 선택지
- 엔딩 2개, 가능한 선택 경로 5개
- 배경 2종, 캐릭터 표정 2종 (서윤 · 망설임/미소)
- 오리지널 BGM 2곡과 효과음 3종
- 페이드, 표정 전환, 장면 자동 연결, BGM 전환, 블록별 효과음

분당 약 900자 읽기와 선택 시간을 기준으로 경로당 약 4.8–4.9분을 목표로 했습니다.
실제 플레이 시간은 읽기 속도·텍스트 속도·자동 진행 설정에 따라 달라집니다. 음성 더빙은 포함하지 않습니다.

## 스포일러: 분기

첫 선택에서 **이야기를 듣기**, 두 번째 선택에서 **하고 싶은 말을 하도록 격려하기**를 고르면 각각 용기 +1을 얻습니다.
용기 2일 때 마지막의 **다음 약속을 적는다**가 열리며 엔딩 A **내일, 이어서**로 갑니다.
**오늘의 날짜를 적고 인사를 남긴다**는 항상 선택할 수 있고 엔딩 B **한 상자 분량의 안녕**으로 갑니다.
엔딩 B도 완결된 결말이며 실패 엔딩은 아닙니다.

## 파일과 재현

- `마지막 방송이 끝나기 전에.hinanastory`: 완성된 편집용 프로젝트
- `build.mjs`: 원문 대본·분기·연출 데이터, 프로젝트 생성 및 경로 검사
- `make-audio.py`: 외부 음원 없이 만든 원본 음악·효과음 생성기
- `assets/`: 원본 이미지·오디오
- `IMAGE-PROMPTS.md`: 내장 image_gen으로 제작한 이미지의 최종 프롬프트 전체
- `routes.json`: 경로별 분량 산정
- `check.mjs`: 실제 웹 재생기로 모든 선택 경로와 두 엔딩을 확인하는 통합 검증
- `verification.json`: 통합 검증 결과
- `preview/`: 배포 재생기로 구성한 웹 미리보기 (생성 후 정적 서버에서 실행)
- `sample-play.png`: 실제 재생 화면
- `studio-editor.png`, `studio-graph.png`: 실제 개발 앱에서 연 편집기·연결 그래프
- `open-in-studio.mjs`: 샘플을 별도 개발 창에서 여는 도구

프로젝트 루트에서:

```sh
python3 examples/last-broadcast/make-audio.py
node examples/last-broadcast/build.mjs
npm run build
node examples/last-broadcast/check.mjs
```

웹 미리보기는 `preview/`에서 `python3 -m http.server 8088` 실행 후 http://localhost:8088 에 접속합니다.
제작기에서 **작품 내보내기**를 사용하면 Windows 게임 배포 폴더도 만들 수 있습니다.
이미지는 내장 `image_gen`으로 생성했고, 대본·음악·효과음은 이번 예시용으로 작성·합성했습니다.
